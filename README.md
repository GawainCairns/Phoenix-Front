# Phoenix Front

A modern React development environment with Tailwind CSS and Vite.

## Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```
   The app will open automatically at `http://localhost:3000`

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Preview production build:**
   ```bash
   npm run preview
   ```

## Tech Stack

- **React 18** - A JavaScript library for building user interfaces
- **Vite** - Next generation frontend tooling with instant HMR
- **Tailwind CSS** - Utility-first CSS framework
- **PostCSS** - Transform styles with JavaScript
- **Autoprefixer** - Parse CSS and add vendor prefixes

## Project Structure

```
phoenix-front/
├── src/
│   ├── main.jsx      # React entry point
│   ├── App.jsx       # Main App component
│   └── index.css     # Tailwind CSS directives
├── index.html        # HTML entry point
├── vite.config.js    # Vite configuration
├── tailwind.config.js # Tailwind configuration
├── postcss.config.js # PostCSS configuration
└── package.json      # Project dependencies
```

## Getting Started

Edit `src/App.jsx` to start developing your React components with Tailwind CSS classes.

Happy coding! 🚀
